## Demo (`tests/psx_3d_demo.exe`, generated by `tools/gen_demo.c`)
- Original MIT PS-X EXE: 395280 bytes, 760 R3000A instructions, assembled by our own MIPS assembler (pure C11, `tools/gen_demo.c`).
- Per frame it:
  - rotates an octahedron with GTE RTPT, NCLIP back-face culling, MVMVA normals, GPF lighting and AVSZ3 OT sorting. It has 4 lit 4bpp-CLUT textured faces and 4 Gouraud faces.
  - draws diagonal background stripes and a 2D HUD (text, frame-driven progress bar, textured sprite).
  - submits the scene through DMA6 OTC and a DMA2 linked list.
- At boot it plays a C4/E4/G4 SPU chord (ADPCM uploaded by DMA4).
- The run is 120 frames, with about 112 GPU prims per frame.
- Outputs are identical on both arches: `out/x86_64/` and `out/aarch64/`. The 5 mode PNGs are frame 60, full 640×480 edge-to-edge:
  - `psx_3d_1x_640x480.png`, `psx_3d_fxaa_640x480.png`, `psx_3d_2x_640x480.png`, `psx_3d_4x_640x480.png`, `psx_3d_8x_640x480.png`
  - `psx_ssaa_compare.png` (1280×704): 5 zoomed edge crops plus 8x vs 1x full frames.
  - `psx_chord_48k.wav`.

## Architecture
- **Phase 0** (`step_cpu_phase`, writes BACK only) runs:
  - the R3000A interpreter (`psx_cpu.c`), the full GTE (`psx_gte.c`), and the bus, DMA, timers, SIO0 pad, CD-ROM no-disc stub and MDEC stub (`psx_bus.c`)
  - the HLE BIOS plus PS-EXE loader (`psx_bios_hle.c`). An optional external 512 KiB BIOS can be loaded with `hs_psx_load_bios`.
  - GP0/GP1 capture (`psx_gpu_cap.c`) into 64-byte `psx_gpu_prim_t` records in the back slot. 2D fills, copies and uploads are applied to VRAM; nothing is rasterized here.
  - SPU register writes and uploads, captured as an event log.
  - At the end of each step, only dirty VRAM rows and dirty 1 KiB SPU-RAM blocks are delta-copied.
- **commit_phase** flips FRONT and BACK.
- **Phase 1** (`render_video_phase`, reads the const FRONT slot): the software rasterizer (`psx_gpu_raster.c`).
  - 28.4 fixed point, top-left fill rule, exact per-row attribute setup.
  - 4/8/15bpp textures, CLUT, texture window, semi-transparency modes 0–3, raw texture, dither and mask in 1x.
  - Modes are 1x (sharp stretch), FXAA, and 2x/4x/8x SSAA strip-tiled via `hs_ssaa_render`, with optional post-FXAA (`hs_psx_set_post_fxaa`).
  - Backend hook: `psx_gpu_backend_t` together with `hs_psx_export_cmdlist` and `hs_psx_render_backend`.
- **Phase 2** (`synth_audio_phase`, `psx_spu.c`) runs 24 voices:
  - ADPCM with loop flags, Gaussian interpolation, ADSR, noise, PMON and main/voice volumes.
  - Native 735 samples per frame at 44.1 kHz stereo int16 (`hs_psx_synth_audio_native`), linearly resampled to the ABI's 800 samples per frame at 48 kHz.
- State: everything lives in `hs_psx_t` (12038944 bytes). There are no mutable globals, no mutexes and no threads. The only PRNG is a fixed-seed LCG for HLE `rand`.

## Known limitations (honest)
- **BIOS:** the HLE covers only a subset of the A0/B0/C0 functions, enough for the PS-EXE homebrew demo. Commercial games need the optional external BIOS, which has not been tested with a real Sony BIOS image (none is available or used).
- **CD-ROM:** no-disc stub only, with no ISO/CUE/XA/CDDA support. This means no commercial-disc boot yet.
- **MDEC:** stub only.
- **Pad and memory card:** digital pad only; no memory card, no analog.
- **GPU:**
  - Rendered polygons are not written back into VRAM, so there is no render-to-texture and no VRAM readback of drawn pixels.
  - Present rect = draw-area origin of the first draw prim, otherwise the display start.
  - Mask bit and dither apply only at 1x, not in SSAA.
  - No rectangle flip bits.
  - Interlace and 24-bit display are only partly handled.
- **Timing:** approximate. 2 CPI, instant DMA, timer sync modes ignored, 60 Hz instead of 59.94.
- **SPU:**
  - No reverb, sweep, SPU IRQ or CD audio.
  - ENDX is not readable by the CPU, because the SPU runs in Phase 2.
  - The Gaussian table is an original sigma-0.75 Q15 kernel, not Sony's table.
- **GTE:** UNR divide is up to 3/65536 off exact, a property of the Newton-Raphson approximation. It has not been checked against hardware captures.
- **Panfrost:** the backend is only the interface; no GPU backend is implemented.
